# Original Bohr comparison

The seven original modules remain at the repository root, unchanged, to preserve
imports, behavior, and the working Pygame environment. Launch with
`.venv/bin/python main.py`. Press 1/2/3 for hydrogen/helium/lithium, P for
hydrogen Bohr physics, Escape to exit. The browser's Classical Comparison tab
explains and links these instructions; it does not start processes from HTTP.
Circular trajectories and shell filling in this original program are educational
approximations. No font or freetype dependency has been introduced.
