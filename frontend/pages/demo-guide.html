Browser calculations, recorded datasets and local research

This public demo runs independently of the author's computer. Calculations run on your device in bounded web workers. Recorded chemistry datasets are labeled; no new HF/DFT calculation is performed by this website. No account, API key or payment is needed to use it.

What works here

LaboratoryExecution and scientific scope
Atomic ExplorerInteractive TypeScript Coulomb radial functions and real/complex spherical harmonics, n=1…8 and s/p/d/f. Up to 8,000 Born-rule cloud samples; 41³ finite-grid isosurfaces and nodes. All 118 elements, curated configurations, ions and isotopes. Many-electron shapes use illustrative Z_eff, not a self-consistent solution.
H₂⁺ bondingInteractive analytic two-center Slater 1s LCAO Hamiltonian, overlap, bonding/antibonding fields, optional common-exponent minimization and energy curve. Includes nuclear repulsion. Not exact H₂⁺ or a many-electron H₂ solver. Even/odd parity labels are retained if a poor trial exponent reverses the finite-basis energy order.
Recorded molecular orbitalsReproducible HF/STO-3G datasets for H₂ (R=1.4 a₀), N₂ (R=2.5 a₀), triplet O₂ (R=2.5 a₀) and water (bundled PubChem3D coordinates). Alpha/beta HOMO, LUMO, density and spin density; fixed 41³ grid and threshold 0.08. PySCF 2.14.0. These geometries are not claimed as experimental equilibria.
MO diagrams & structuresTen qualitative diatomic occupation diagrams; six bundled source-preserved PubChem3D conformers. Reference occupations and conformer coordinates are precomputed/source data, not live molecular energies or geometry optimization.
SpectroscopyInteractive reduced-mass hydrogenic energies, vacuum wavelengths, E1 rules, spin and polarization. Radial and angular dipole coefficients were reproducibly precomputed with Python quadrature; state selection and scaling execute in the browser. No fine structure, QED or absolute intensities.
MeasurementInteractive, seeded Born-rule radial sampling and accumulation/reset; prepared-state uncertainties. Browser PRNG is Mulberry32, so the same seed does not reproduce NumPy's exact samples. No electron trajectories or simultaneous exact position/momentum.
Quantum DynamicsInteractive exact two-state infinite square well with complex coefficients and playback. Other evolution solvers require the local Python environment.
Ideal circuitsInteractive state-vector simulation: 1…4 qubits, ≤32 gates and ≤5,000 final shots. No hardware or noise claim. q0 is the rightmost bit.
Quantum MaterialsInteractive analytic chain, square and honeycomb nearest-neighbor tight-binding bands and finite BZ DOS. Illustrative input parameters, no real-material reference dataset or periodic DFT.

Advanced local environment

The full scientific Python source is preserved in the repository: live HF/DFT across the full molecule catalog, larger bases, geometry optimization, vibrations, correlated methods, electronic response, VQE, general/3D atomic dynamics, tunneling, Lindblad and field experiments. Those computations are unavailable in this static build unless explicitly listed above. An unavailable solver displays a clear message instead of fabricated results.

Repository, source and local setup. Use Python 3.14.7, install the documented requirements, build the normal frontend and run QAL_MODE=local python run.py. The Railway Docker option remains separate.

Reproducibility & limits

Dataset manifest and SHA-256 hashes · Build provenance

Run scripts/generate_static_data.py with the pinned/documented local scientific dependencies to regenerate source tables. Bundled isotope/configuration/conformer provenance is recorded in quantum_engine/data/SOURCES.md. Exported figures and tables retain model/parameter labels.

Browser finite-grid surfaces and numerical CDF/angle quadratures have discretization error. High-n inner lobes may be unresolved. Isosurface thresholds are fractions of the sampled amplitude peak, not enclosed probability. Atomic density is stationary for an energy eigenstate; cloud dots are possible independent measurements, not trajectories.

Workers terminate when requests are superseded and after a 15-second deadline. Result caches are bounded; WebGL renderers are reused with resource cleanup. Browser memory and performance vary by device.

Static assets only: no Pages Functions, Workers bindings, database, paid API, tunnel or dependency on an online Mac. Hosting is intended for Cloudflare Pages Free with a free pages.dev address, within its limits. No credit card or paid feature is required by this application.
